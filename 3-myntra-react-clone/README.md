# Myntra Clone

A fully responsive E-commerce web application inspired by Myntra, built using React and modern frontend tools. The application enables users to browse fashion products, manage shopping bags, wishlist items, and experience a seamless online shopping interface.

## Overview

Myntra Clone is a feature-rich frontend application designed to mimic the core functionalities of the popular e-commerce platform Myntra. Users can explore various product categories, add or remove items from their shopping bag, manage wishlists, and view dynamic price summaries. Built with a clean component-based architecture, it delivers a fast and responsive shopping experience across desktop and mobile devices.

## Features

### User Features
* **Product Catalog:** Browse through a wide range of fashion and lifestyle products.
* **Bag & Cart Management:** Add items to your shopping bag, update quantities, and calculate total prices dynamically.
* **Wishlist Integration:** Save and manage your favorite items for later purchases.
* **Responsive Layout:** Clean and optimized design that adapts smoothly to different screen sizes.

### General Features
* Component-based React architecture
* State management for cart and items
* Fast development and bundling with Vite
* Modern UI styling with CSS3
